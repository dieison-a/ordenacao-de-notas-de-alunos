# Ordenação de notas de alunos

Apresenta as versões do exercício de notas e ordenação, mantendo cada código na sua etapa.

## Executar

Cada versão deve ser iniciada na própria pasta. Exemplo:

```powershell
cd etapas\semana-03-e-04
php -S localhost:8000
```

Acesse http://localhost:8000. Troque a pasta pela versão que deseja executar.

## Versões preservadas

- `etapas/semana-03-e-04`: Semana 03 e 04\Dieison-Alessi-Ex3.3
- `etapas/semana-05-e-06`: Semana 05 e 06\Dieison-Alessi-Ex3.3
